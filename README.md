## 🌕 Project Overview

**Moon Rabbit**은 달에 정착한 토끼가 다양한 활동을 통해 재료를 모으고,
떡을 만들어 판매하며 자신의 생활 공간을 성장시키는 **웹 기반 생활 게임**입니다.

NAN 2026 대회를 준비하며
단순한 아이디어 제안에 그치지 않고 **게임의 세계관부터 플레이 구조, 경제 시스템, UI와 실제 기능 구현까지 직접 설계하고 개발**했습니다.

완성된 상용 게임보다는,

> **“짧은 기간 안에 하나의 게임 아이디어를 실제 플레이 가능한 형태로 어디까지 구현할 수 있을까?”**

를 직접 시험해 본 프로젝트입니다.

---

## 🐇 Game Concept

플레이어는 **달토끼**가 되어 달에서 생활합니다.

생활 활동을 통해 재료를 획득하고,
획득한 재료로 떡을 제작한 뒤 판매하여 자산을 늘려갑니다.

### 🌲 Collect

직접 캐릭터를 움직이며 다양한 생활 콘텐츠를 진행합니다.

* 🎣 낚시
* 🌲 벌목
* 🏹 수렵
* ✨ 희귀 재료 획득

### 🍡 Craft

수집한 재료를 활용해 다양한 떡을 제작합니다.

**기본 떡 → 색깔 떡 → 희귀 재료를 활용한 특별한 떡**

단순 반복 생산이 되지 않도록
재료의 희귀도와 떡의 가치에 차이를 두는 구조를 고민했습니다.

### 💰 Trade

떡의 종류에 따라 판매 방식을 다르게 설계했습니다.

* 기본 떡 : 고정 가격
* 색깔 떡 : 날짜에 따라 가격 변동
* 특별한 떡 : 높은 희소성과 판매 가치

플레이어가 단순히 아이템을 모으는 것에서 끝나지 않고
**“지금 판매할 것인지, 더 가치 있는 떡을 만들 것인지”** 판단할 수 있도록 경제 요소를 추가했습니다.

### 🏠 Grow

획득한 재화는 다시 플레이어의 성장으로 연결됩니다.

생활 공간과 보관 시스템을 성장시키면서
더 많은 활동을 할 수 있는 **수집 → 제작 → 판매 → 성장**의 게임 루프를 설계했습니다.

## 🎮 What I Built

이 프로젝트에서는 게임 플레이뿐만 아니라
**게임을 구성하는 전체 흐름을 직접 설계하는 경험**에 집중했습니다.

### Game Design

* 달토끼 콘셉트 및 세계관 기획
* 핵심 게임 루프 설계
* 생활 콘텐츠 구조 설계
* 아이템 희귀도 및 보상 구조 기획
* 떡 제작·판매 경제 시스템 설계
* 플레이어 성장 구조 기획

### Development

* 웹 환경에서 게임 화면 구현
* 캐릭터 이동 및 상호작용 구현
* 생활 콘텐츠 기능 구현
* 상점 및 인벤토리 UI 구현
* 아이템 획득·보관·판매 흐름 구현
* 게임 내 시간 흐름 및 UI 요소 구현

### Development Environment

* Git 기반 버전 관리
* 기능 단위 개발 및 지속적인 UI 개선
* 브라우저 환경에서 플레이 가능한 게임 프로토타입 제작

## 🎨 About Visual Assets

게임의 **기획, 시스템 설계 및 기능 구현은 직접 진행**했으며,
프로토타입 제작 속도를 높이기 위해 일부 캐릭터와 배경 등의 시각 에셋 제작 과정에서는 생성형 AI 도구를 보조적으로 활용했습니다.

이 과정에서 생성형 이미지가 빠른 프로토타이핑에는 효과적이지만,

* 동일 캐릭터의 외형 일관성
* 다양한 동작의 연속된 에셋 제작
* 전체 게임의 아트 스타일 통일

등에서는 분명한 한계가 있다는 것도 직접 경험할 수 있었습니다.

## 🧪 Prototype & Experiment

이 프로젝트는 대회 준비 과정에서 시작한 **실험적인 개인 게임 프로젝트**입니다.

게임 개발 경험이 많지 않은 상태에서
직접 게임의 규칙을 정의하고 이를 코드로 구현하면서,

**아이디어 → 시스템 설계 → UI → 실제 플레이**

까지 연결해 보는 것을 목표로 했습니다.

프로토타입 단계까지 개발한 뒤 프로젝트를 마무리했지만,
이를 통해 기능 구현뿐만 아니라 **게임에서는 시스템 간 연결과 사용자 경험까지 함께 설계해야 한다는 점**을 경험할 수 있었습니다.

---

## 💡 What I Learned

> 좋은 아이디어를 생각하는 것과
> 그 아이디어를 실제로 동작하는 서비스로 만드는 것은 전혀 다른 문제였습니다.

게임 하나를 구현하기 위해서도
UI, 상태 관리, 사용자 입력, 아이템, 경제 시스템, 콘텐츠 간의 연결을 모두 고려해야 했습니다.

또한 개발 범위와 시간, 디자인 리소스를 직접 고려하면서
**프로젝트에서 구현 범위를 결정하고 우선순위를 조정하는 경험**을 할 수 있었습니다.
